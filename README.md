# OMR શીટ અને ચેકર

મોબાઇલથી OMR શીટ બનાવો, ફોટો લઈને ચકાસો અને પરિણામ Excel માં મેળવો.

- 10 થી 100 પ્રશ્નો, વિકલ્પ A B C D / અ બ ક ડ
- રોલ નંબર 4 અથવા 8 અંક
- સાચા જવાબના ગુણ અને ખોટા જવાબ પર માઇનસ માર્કિંગ
- લાલ અથવા કાળી શીટ (A4 PDF)
- કેમેરાથી સ્કેન, ટેપ કરીને સુધારો, Excel નિકાસ

આખી એપ એક જ ફાઇલ `index.html` માં છે. ડેટા ફોનના બ્રાઉઝરમાં સેવ થાય છે.
